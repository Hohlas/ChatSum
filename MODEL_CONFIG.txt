# Все варианты, которые знает код, — у каждой модели свой чанк-профиль.
# Только для чтения: строки закомментированы, потому что при /model бот удаляет
# живую строку <ПРОВАЙДЕР>_MODEL= и дописывает её в конец файла. Живые
# параметры — в блоках провайдеров ниже, активная модель — в конце файла.
# Формат: модель, рядом её CHUNK_MAX_CHARS, в комментарии — контекст / потолок ответа.
# Чанк — в символах русского текста; в JSON-запросе ~2.6 знака на токен.
#
