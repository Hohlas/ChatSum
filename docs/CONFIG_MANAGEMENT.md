# Управление конфигурацией бота

## 📁 Конфигурационные файлы

Бот использует четыре текстовых файла для хранения настроек:

### 1. `EXCLUDED_USERS.txt`
Список пользователей, сообщения которых исключаются из анализа.

**Формат:**
- Один пользователь на строку
- Или разделенные пробелами, запятыми, точкой с запятой
- Строки начинающиеся с `#` игнорируются (комментарии)

**Пример:**
```
# Исключенные пользователи
AntonHoldon
gtslay, E2ard
vlad_calista
```

### 2. `PRIORITY_USERS.txt`
Список приоритетных пользователей, чьи сообщения выводятся первыми в анализе.

**Формат:** аналогичен `EXCLUDED_USERS.txt`

**Пример:**
```
# Приоритетные пользователи
Zinur
Restyle Pon
Lex, ProMint, Sergey
```

### 3. `PROMPT.txt`
Промпт для Google Gemini API, определяющий как именно анализируются сообщения. Можно редактировать для изменения структуры выжимки.

**Формат:** произвольный текст

### 4. `MODEL_CONFIG.txt`
Настройки модели AI для анализа.

**Формат:**
```
MODEL=gemini-1.5-flash
USE_REASONING=false
```

**Доступные модели:**
- `gemini-1.5-flash` - базовая модель (быстрее и дешевле) ⭐
- `gemini-1.5-pro` - более мощная модель для сложных задач

**Примечание:** Для работы используется Google AI Studio API. Вы можете получить бесплатный ключ для этих моделей.

## 🎮 Управление через Telegram

Все конфигурационные файлы можно редактировать прямо из мессенджера!

### Просмотр конфигурации

| Команда | Описание |
|---------|----------|
| Команда | Описание |
|---------|----------|
| `/config` | Показать полную конфигурацию |
| `/show_excluded` | Список исключенных пользователей |
| `/show_priority` | Список приоритетных пользователей |
| `/show_prompt` | Показать текущий промпт (первые 1000 символов) |
| `/show_model` | Показать текущую модель и настройки |

### Управление исключенными пользователями

```
/add_excluded username     # Добавить пользователя
/remove_excluded username  # Удалить пользователя
```

**Примеры:**
```
/add_excluded SpamBot
/add_excluded John Doe
/remove_excluded gtslay
```

### Управление приоритетными пользователями

```
/add_priority username     # Добавить пользователя
/remove_priority username  # Удалить пользователя
```

**Примеры:**
```
/add_priority Alice
/remove_priority Bob
```

### Управление моделью AI

```
/set_model gemini-1.5-flash    # Установить модель Flash
/set_model gemini-1.5-pro      # Установить модель Pro
/show_model                    # Показать текущую модель
```

**Примечание:** Модель сохраняется в `MODEL_CONFIG.txt` и применяется при следующем анализе.

### Перезагрузка конфигурации

```
/reload_config
```

Используйте эту команду после редактирования файлов напрямую на сервере.

## 🖥️ Редактирование на сервере

### Способ 1: Через nano/vim
```bash
cd ~/ChatSum
nano EXCLUDED_USERS.txt
# Редактируем, сохраняем (Ctrl+O, Enter, Ctrl+X)
```

В мессенджере:
```
/reload_config
```

### Способ 2: Через команды
```
/add_excluded NewUser
/show_excluded  # Проверяем
```

### Способ 3: Через git
1. Редактируем локально в IDE
2. Коммитим и пушим
3. На сервере: `git pull`
4. В мессенджере: `/reload_config`

## 💡 Рекомендации

1. **Резервные копии**: Перед массовым редактированием делайте копии файлов
2. **Комментарии**: Используйте `#` для пояснений в списках пользователей
3. **Имена**: Используйте точные имена пользователей как они отображаются в чате
4. **Промпт**: При изменении промпта тестируйте на небольшом чате сначала
5. **Синхронизация**: После изменений на сервере используйте `/reload_config`

## 🔄 Workflow

### Добавить нового исключенного пользователя (быстро)
```
/add_excluded SpammerName
```

### Обновить промпт (детально)
1. Локально отредактировать `PROMPT.txt`
2. `git add PROMPT.txt && git commit -m "Update prompt" && git push`
3. На сервере: `git pull`
4. В Telegram: `/reload_config`
5. В Telegram: `/show_prompt` (проверить)

### Изменить модель AI
```
/set_model gemini-1.5-flash
/show_model  # Проверить
```

Или отредактировать `MODEL_CONFIG.txt` напрямую и выполнить `/reload_config`.

### Массовое обновление списков
1. Редактируем `EXCLUDED_USERS.txt` и `PRIORITY_USERS.txt` локально
2. Тестируем синтаксис (убедитесь что нет опечаток)
3. Коммитим и пушим
4. На сервере: `git pull`
5. В Telegram: `/reload_config`
6. В Telegram: `/config` (проверить все настройки)

## ⚠️ Важные моменты

1. **Регистр**: Имена пользователей чувствительны к регистру
2. **Пробелы**: Имена с пробелами поддерживаются (например "John Doe")
3. **Автосохранение**: Изменения через команды бота сохраняются автоматически
4. **Конфликты**: При работе с git избегайте одновременного редактирования
5. **Кодировка**: Файлы должны быть в UTF-8 для поддержки кириллицы

## 📋 Формат JSON экспорта

При использовании команды `/copy` создается JSON файл в оптимизированном формате v2.0:

**Структура:**
```json
{
  "metadata": {
    "chat_id": "1675726024",
    "period_start": "2025-11-19 17:55:17",
    "chat_name": "ProChat",
    "export_date": "2025-11-20 06:24:17",
    "total_messages": 52,
    "filtered_messages": 51
  },
  "messages": [
    {
      "id": 243613,
      "s": "Insey",           // sender (отправитель)
      "t": "Текст сообщения",  // text (текст)
      "r": [                   // replies (ответы, опционально)
        {
          "id": 243616,
          "s": "Artem Mashura",
          "t": "Ответ на сообщение",
          "r": []  // вложенные ответы
        }
      ]
    }
  ]
}
```

**Оптимизация:** Используются короткие ключи (`s`, `t`, `r`) вместо полных названий для экономии токенов при отправке в API.
