# ChatSum

Открываешь чат после пары дней тишины — а там уже тысяча новых сообщений.
Одна команда — и вместо бесконечной ленты получаешь стройный разбор:
всё разложено по темам, сжато до сути, каждый вывод подкреплён цитатой.
Бежишь глазами по заголовкам, останавливаешься только на важном.
Захотел подробностей — читаешь короткие выжимки из слов участников
и по ссылке прыгаешь точно к месту спора в чате.

Тысячи сообщений в чате — одна команда, и получаешь аккуратный разбор:
главные темы, кто что говорил, важные ссылки и цифры. Не надо листать
чат за неделю — бот прочитает всё сам и разложит по полочкам.

## Что он умеет

- **Саммари за период:** «что было в чате за последние 12 часов / 2 дня».
- **Саммари по количеству:** «разбери последние 50 сообщений».
- **Саммари по расписанию:** каждое утро получаешь дайджест чата сам, без команд.
- **Выгрузка без нейросети:** сохранить переписку текстом, чтобы разобрать вручную.

## Основные команды

```text
/sum 12h     — что было в чате за последние 12 часов
/sum 2d      — за последние 2 дня
/sum 50      — последние 50 сообщений
/copy 100    — сохранить последние 100 сообщений без анализа (бесплатно)
/sch ...     — настроить ежедневный дайджест (подробности ниже)
```

Команды отправляются прямо в чат — бот работает с твоего аккаунта
и отвечает там же.

## Два способа запуска

|  | Свой сервер (VPS) | GitHub Actions (бесплатно) |
|---|---|---|
| Что нужно | Компьютер или сервер, который всегда включён | Только аккаунт GitHub, сервера не надо |
| Как работает | Бот постоянно на связи, отвечает сразу | Бот просыпается по расписанию и по твоим командам |
| Команды | Прямо в любом чате: `/sum 12h` | В общем чате: `sum50` + ссылка на чат |

Можно только один способ за раз — оба сразу не работают.

## Установка

### Что нужно заранее (для обоих способов)

Два бесплатных ключа:

1. **Ключи Telegram:** открой https://my.telegram.org/auth, войди по номеру
   телефона, затем `API development tools` → создай приложение → скопируй
   `api_id` и `api_hash`.
2. **Ключ Gemini:** открой https://aistudio.google.com, создай API-ключ.

### Вариант 1. Свой сервер

```bash
git clone https://github.com/Hohlas/ChatSum.git && cd ChatSum
./scripts/setup.sh        # проверит Python, поставит всё нужное
# заполни private.txt ключами из прошлого шага:
cp private.txt.example private.txt
```

Минимальное содержимое `private.txt`:

```env
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=0123456789abcdef0123456789abcdef
TELEGRAM_PHONE=+79991234567

GOOGLE_API_KEY=AIzaSyExampleKey
GEMINI_MODEL=gemini-3.6-flash
```

Запуск:

```bash
python3 main.py           # обычный запуск
./scripts/start_bot_background.sh   # в фоне, чтобы работал после закрытия окна
```

При первом запуске Telegram пришлёт код подтверждения на твой номер —
введи его в окно запуска. Дальше заходи в любой чат и пиши `/sum 12h`.

Ежедневный дайджест настраивается командой прямо в чате, например
`/sch 08:00 1d` — каждое утро в 8:00 будет саммари чата за сутки.

### Вариант 2. GitHub Actions (без сервера)

1. Нажми Fork на странице проекта и склонируй **свой** форк.
2. Выполни шаги из варианта 1 до `private.txt` включительно.
3. Сгенерируй строку сессии: `./venv/bin/python tools/gen_session.py`.
4. Залей ключи в GitHub: `./scripts/push_github_secrets.sh`.
5. Открой в расписании файл `SCHEDULE.txt` — каждая строка это
   `номер-чата|время|охват`, например `-1001234567890|08:00|1d`
   (дайджест каждое утро в 8:00). Закоммить и запушь.
6. Запусти вручную: Actions → ChatSum scheduled summaries → Run workflow.
   Дальше бот просыпается сам каждые ~11 минут.

Разовые команды — в общем чате бота: `sum50` + ссылка на чат
(например, `sum50 t.me/название_чата`). Выполненная команда исчезает сама.

## Если что-то пошло не так

- **«429 quota exceeded»** — закончился бесплатный лимит Gemini. Подожди
  до завтра или добавь ещё ключи (`GOOGLE_API_KEY1`, `GOOGLE_API_KEY2`…).
- **Telegram снова просит код** — сессия слетела, просто пройди вход заново.
- **Бот молчит** — проверь, что заполнены все ключи в `private.txt`
  и что процесс запущен (для VPS).
