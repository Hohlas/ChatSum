# ⚡ Быстрый старт

Минимальное руководство для быстрого запуска Telegram Chat Analyzer.

---

## 📦 За 5 минут

### 1. Получите API ключи

#### Telegram API (2 минуты)
1. Откройте https://my.telegram.org/auth
2. Войдите с номером телефона
3. Перейдите в "API development tools"
4. Создайте приложение
5. Скопируйте `api_id` и `api_hash`

#### Google Gemini API (2 минуты)
1. Откройте [Google AI Studio](https://aistudio.google.com)
2. Получите API ключ (бесплатно для большинства моделей)
3. Скопируйте ключ и сохраните его

## 🔑 Настройка private.txt

При первом запуске бот автоматически создаст файл `private.txt` из шаблона `private.txt.example`.

**Откройте `private.txt` и заполните вашими реальными ключами:**

```
# Telegram API
TELEGRAM_API_ID=12345678
TELEGRAM_API_HASH=abcdef1234567890abcdef1234567890
TELEGRAM_PHONE=+79001234567

# Google Gemini API
GOOGLE_API_KEY=ваш_google_ключ
GEMINI_MODEL=gemini-1.5-flash

# ID канала для публикации результатов (опционально)
TELEGRAM_GROUP_ID=-1001234567890
```

**⚠️ Важно:**
- `TELEGRAM_API_ID` - только цифры, БЕЗ кавычек
- `TELEGRAM_PHONE` - в формате `+79001234567` (код страны + номер)
- Не публикуйте эти ключи!

> 💡 **Совет:** Если файл не создался автоматически, скопируйте `private.txt.example` в `private.txt` и отредактируйте его.

1. **Откройте Telegram** на телефоне/компьютере

## 🔧 Решение проблем

### Бот не запускается

**Проверьте:**
1. Python установлен: `python --version` (нужна версия 3.8+)
2. Зависимости установлены: `pip list | grep telethon`
3. Файл `private.txt` существует и заполнен правильно

**Типичные ошибки:**

| Ошибка | Решение |
|--------|---------|
| `ModuleNotFoundError` | `pip install -r requirements.txt` |
| `ValueError: invalid literal` | Проверьте `TELEGRAM_API_ID` (без кавычек) |
| `FileNotFoundError` | Файл `private.txt` должен создаться автоматически. Если нет, скопируйте `private.txt.example` в `private.txt` |

### Бот не реагирует на команды

**Проверьте:**
1. Бот запущен (в консоли должно быть "👀 Ожидание команд...")
2. Команда начинается с `/` (слеш)
3. Команда отправлена **от вашего имени** (не от бота)

### Ошибка API ключа

**Решение:**
1. Проверьте ключ в [Google AI Studio](https://aistudio.google.com)
2. Убедитесь, что скопировали полностью
3. Проверьте баланс аккаунта
4. Попробуйте создать новый ключ

## 💡 Советы

### ✅ Хорошие практики

1. **Безопасность:**
   - Никогда не публикуйте `private.txt`
   - Не делитесь файлом `*.session`

2. **Эффективность:**
   - Используйте короткие периоды для быстрого анализа
   - Длинные периоды (7d+) для отчетов

3. **Настройка:**
   - Измените `ANALYSIS_PROMPT` под свои нужды
   - Экспериментируйте с различными промтами

### ❌ Частые ошибки

1. **Не запускайте** несколько копий бота одновременно
2. **Не используйте** один аккаунт с нескольких устройств
3. **Не превышайте** лимиты API (слишком частые запросы)

## 🎓 Что дальше?

### Кастомизация

1. **Измените промт** для вашей области:
   ```python
   # В main.py
   ANALYSIS_PROMPT = """Ваш промт для технических/бизнес/медицинских чатов"""
   ```

2. **Настройте период по умолчанию:**
   ```python
   # В main.py, функция handle_analyze_command
   hours = 12  # Вместо 24
   ```

3. **Измените модель AI:**
   ```python
   # В main.py, функция create_summary
   model='sonar-large-online'  # Для более точного анализа
   ```
