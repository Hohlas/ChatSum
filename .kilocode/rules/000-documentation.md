# Правило: Стандарт документирования кода

## Применение
При создании новых файлов или документировании существующих.

## Языки проекта
Python, MQL4, Jupyter Notebooks

## Структура File Header

Добавь в начало **каждого файла**:

```python
# =============================================================================
# Файл: [имя файла]
# Назначение: [Одна строка — что делает скрипт]
# Язык: Python/MQL4/Jupyter
# Обновлён: [YYYY-MM-DD]
# Зависимости:
#   Входные данные:
#     - [путь/файл] (откуда: [источник])
#   Выходные данные:
#     - [путь/файл] (куда используется: [назначение])
# Внешние зависимости:
#   - [библиотека>=версия]
# Использование:
#   [команда запуска]
# Примечания:
#   - [важные ограничения или особенности]
# =============================================================================
```

Для MQL4 используй //+--...--+ рамку вместо '#'

## Docstrings (Python)
Module-level (сразу после file header)

```python
"""
Краткое описание модуля (1-2 предложения).

Более детальное описание функциональности, если нужно.
"""
```

### Функции и классы

```python
def process_data(input_file: str, threshold: float = 0.5) -> pd.DataFrame:
    """
    Краткое описание функции.
    
    Аргументы:
        input_file: Путь к входному CSV файлу
        threshold: Порог для фильтрации (по умолчанию 0.5)
        
    Возвращает:
        DataFrame с обработанными данными
        
    Исключения:
        FileNotFoundError: Если входной файл не найден
        
    Пример:
        >>> df = process_data('data.csv', threshold=0.7)
    """
```

## Комментарии в коде
НЕ комментируй очевидное:

```python
# ❌ Плохо
x = 10 # Инициализация переменной

# ✅ Хорошо
MAX_RETRIES = 10 # Количество попыток подключения к API
```

Комментируй "почему", не "что":
```python
# ✅ Хорошо
# Используем RobustScaler, так как ATR имеет выбросы в периоды волатильности
scaler = RobustScaler()
```

## Резюме после документирования
После обновления файла предоставь:
```markdown
## Резюме документации

**Файл**: [имя]  
**Назначение**: [краткое описание]

**Основные компоненты**:
- `function_name()`: [назначение]

**Поток данных**:
- Вход: [источники]
- Выход: [назначения]

**Зависимости**: [внешние библиотеки]
```

## Языковые соглашения
✅ На русском: docstrings, комментарии, file headers, документация 
✅ На английском: имена переменных, функций, классов, файлов 
✅ Термины: При первом упоминании — "конвейер (pipeline)"
